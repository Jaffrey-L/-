# AI 新闻情报站开发计划

更新时间：2026-05-15

## 1. 产品定位

AI Daily Radar 不是普通新闻中转页，而是面向 AI 爱好者、企业应用观察者、产品/研发/创业者的 AI 情报工作台。

核心价值：

- 每天快速知道 AI 圈真正重要的技术、产品、应用方法更新。
- 减少低价值通知、重复转述、标题党和普通媒体噪音。
- 把官方新闻、核心博主、实战方法、国内外前沿整合成可读、可筛选、可复盘的情报流。
- 让用户每天打开后先看到“今天最值得看什么”，再按兴趣深入阅读。

## 2. 目标用户画像

主用户：AI 爱好者

- 每天或每周固定追踪 AI 前沿。
- 关注 OpenAI、Anthropic、Google DeepMind、Meta AI、xAI、DeepSeek、阿里通义、豆包、腾讯混元等公司动态。
- 关注 Andrej Karpathy、Simon Willison、Ethan Mollick、swyx、Lilian Weng、Chip Huyen 等博主。
- 特别关心 Agent、Prompt、Vibe Coding、企业应用、模型能力、开源生态和个人效率工具。

次用户：企业应用观察者

- 想知道哪些 AI 能力可以落到产品、运营、研发、管理流程里。
- 更关心“有什么用”“怎么用”“是否值得跟进”，而不只是新闻标题。

## 3. 当前基线

截至 2026-05-15：

- 已有静态前端页面。
- 已有 `data/news.json` 数据文件。
- 已有每 12 小时 systemd 自动更新。
- 已覆盖 2026 年至今新闻。
- 已支持日期、分类、来源、信源级别、关键词、排序筛选。
- 已部署到本地服务器 `http://192.168.1.242:8088`。

当前主要短板：

- 摘要较模板化，尚未真正读懂文章。
- 同一事件存在重复卡片。
- 没有“今日必看 Top 10”。
- solo builder / AI 个人公司内容不足。
- 缺少已读、收藏、稍后看、导出等日常使用能力。
- 来源健康状态不透明。

## 4. 总体路线

### 阶段 1：内容质量升级

目标：从新闻索引升级为可读 AI 情报。

优先级：P0

交付项：

- 真实文章抓取正文。
- AI 中文摘要。
- 每条内容生成四段信息：发生了什么、为什么重要、对企业/个人有什么启发、适合谁看。
- 去重聚合：同一事件合并为一张事件卡，保留多个来源。
- 修复旧文案，例如“近 30 天 AI 情报流”统一为“今年至今 / 今日 / 本周”。

验收标准：

- 首页前 20 条不再出现明显重复事件。
- 每条卡片摘要不是模板句，而是与原文内容相关。
- 每条卡片至少包含 2 条具体要点。
- 至少 80% 内容有中文摘要。
- 自动化数据校验通过。

### 阶段 2：首页情报层级

目标：用户每天打开后先知道最重要的 10 条。

优先级：P0

交付项：

- 增加“今日必看 Top 10”模块。
- 增加“本周关键趋势”模块。
- 增加“新增内容数 / 重要内容数 / 方法论内容数 / 官方发布数”指标。
- 信息流默认按综合优先级，而不是单纯按时间。

验收标准：

- 首屏可看到 Top 10 入口或 Top 10 内容。
- 每条 Top 内容有推荐理由。
- 同一事件不会在 Top 10 重复出现。
- 可切换查看全部信息流。

### 阶段 3：来源覆盖补强

目标：保证核心源头都有稳定内容。

优先级：P0/P1

交付项：

- 核心 AI 公司官方源补强。
- 核心 AI 博主源补强。
- solo builder / AI 个人公司源补强。
- 国内前沿源补强。
- 来源健康检查：成功、失败、fallback、最近更新时间。

重点来源：

- 公司：OpenAI、Anthropic、Google DeepMind、Meta AI、xAI、Microsoft AI、NVIDIA、Hugging Face、DeepSeek、阿里通义、豆包、腾讯混元、百度文心、华为盘古、小米 AI。
- 博主：Andrej Karpathy、Simon Willison、Ethan Mollick、swyx、Lilian Weng、Chip Huyen、Andrew Ng、Yann LeCun、Harrison Chase、Jerry Liu、Jay Alammar。
- 个人公司/solo builder：Pieter Levels、Marc Lou、Danny Postma、Jon Yongfook、Arvid Kahl、Tony Dinh、宝玉、归藏、白宦成、阿文菌。

验收标准：

- 核心来源池中每个来源都有健康状态。
- 核心来源失败时在页面或报告中可见。
- solo builder 内容不再为 0。
- Andrej Karpathy 等重点博主如有近期文章，必须能被发现或记录为无新增。

### 阶段 4：阅读效率与个人化

目标：让用户长期每天使用。

优先级：P1

交付项：

- 已读状态。
- 收藏。
- 稍后看。
- 只看方法论。
- 只看企业应用。
- 中英对照开关。
- 原文可信度标识：官方、一手博客、媒体转述、社区讨论。

验收标准：

- 用户能标记已读和收藏。
- 页面刷新后状态可保留。
- 可通过筛选快速找到收藏内容。
- 中英文信息不会混乱堆叠。

### 阶段 5：输出与订阅

目标：把情报变成可复用日报。

优先级：P2

交付项：

- Markdown 日报导出。
- 微信/飞书风格摘要导出。
- 每日固定时间生成摘要。
- 趋势榜：公司热度、模型热度、关键词热度。

验收标准：

- 能一键复制或导出日报。
- 日报包含 Top 10、趋势、方法论、来源链接。
- 导出内容可直接发给他人阅读。

## 6. 每次打开项目的复盘流程

每次开始新任务前，先看：

1. `docs/project/AI新闻情报站_开发计划.md`
2. `docs/project/AI新闻情报站_进度记录.md`
3. 当前 `git status`
4. 最近一次进度记录的“下一步”
5. 远程站点是否可访问
6. 自动更新 timer 是否正常

推荐复盘命令：

```powershell
git status --short --branch
python scripts/validate_news_data.py
$env:SITE_URL='http://192.168.1.242:8088'; npm.cmd run validate:frontend
```

## 7. 每次执行后的记录要求

每次任务结束后，必须在 `AI新闻情报站_进度记录.md` 追加一条记录。

记录至少包含：

- 日期时间
- 本次目标
- 实际完成
- 改动文件
- 验证证据
- 剩余问题
- 下一步建议

没有验证证据时，不写“完成”，只能写“已修改，待验证”。

## 8. 质量红线

- 不允许把普通通知伪装成重要 AI 情报。
- 不允许重复事件刷屏。
- 不允许摘要只有模板句。
- 不允许来源失败但页面无提示。
- 不允许只显示标题、让用户自己判断价值。
- 不允许牺牲阅读效率追求视觉效果。
